"How long to the airport right now?"

## Setup

1. In the same Google Cloud project you used for
   [Calendar](/integrations/google-calendar/) or [Gmail](/integrations/gmail/),
   enable the **Places**, **Directions** and **Distance Matrix** APIs and
   create an API key.
2. Set it:

   ```bash
   export GOOGLE_MAPS_API_KEY=...
   ```
